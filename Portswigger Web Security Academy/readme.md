# Web Application Security

Notes: https://rounded-trader-1c3.notion.site/Web-Application-Security-3037f3e6c6cb807aae63c4158dc0c574

## Overview

This repository reflects hands-on experience in web application security, gained through practical testing, structured lab work, and active bug bounty hunting. The linked Notion workspace contains detailed notes covering vulnerability classes, exploitation techniques, and methodologies developed and refined through direct application against real and lab-based targets.

## Areas of Focus

- **Broken Access Control (BAC) and IDOR** — Identification and exploitation of authorization flaws, including horizontal and vertical privilege escalation scenarios.
- **Server-Side Request Forgery (SSRF)** — Techniques for detecting and exploiting SSRF across common application architectures, including cloud metadata endpoint abuse.
- **Client-Side Path Traversal (CSPT)** — In-depth analysis of vulnerable JavaScript patterns, traversal encoding techniques, and chaining CSPT to achieve CSRF-like impact.
- **Authentication and Session Security** — Testing of session management, cookie handling, and authentication bypass conditions.
- **API Security** — Testing of GraphQL and REST APIs for authorization inconsistencies and logic flaws.

## Practical Application

- Completed a substantial portion of the PortSwigger Web Security Academy labs, with concentrated work in access control, IDOR, and SSRF categories.
- Active bug bounty researcher on Bug Crowd & HackerOne, applying these techniques against live, in-scope targets as part of ongoing vulnerability research.
- Notes are maintained as a continuously updated reference, documenting both the theory behind each vulnerability class and the practical steps used to identify and validate findings.

## Purpose of This Documentation

The linked notes serve as a working record of applied security research rather than a static study guide. Each section reflects testing performed, patterns observed, and lessons drawn from real engagements and lab environments, intended to demonstrate practical, evidence-based understanding of web application security.
