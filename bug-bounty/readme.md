# Bug Bounty and VDP Findings

## Overview

This repository documents active participation in Vulnerability Disclosure Programs (VDPs) and bug bounty programs through Bugcrowd & HackerOne or any other platform. It serves as a record of vulnerability research and reported findings, demonstrating consistent, hands-on engagement with real-world targets under responsible disclosure guidelines.

Target names, domains, and any client-identifying information have been intentionally omitted or redacted in accordance with program disclosure policies and non-disclosure obligations. Each entry focuses on the technical substance of the finding rather than the identity of the program.

## Purpose

The goal of this repository is to provide verifiable proof of work in offensive security research, showing:

- Consistent, ongoing participation in live bug bounty and VDP programs.
- The range and depth of vulnerability classes identified and reported.
- The methodology used to discover, validate, and report each finding.
- Professional handling of responsible disclosure, including respect for scope and confidentiality requirements.

## Structure of Each Finding

Each documented finding generally includes the following, with target-identifying details removed:

- **Vulnerability Class** - e.g., IDOR, Broken Access Control, SSRF, CSPT, Authentication/Session flaws, API logic flaws.
- **Summary** - A brief, sanitized description of the issue and its context within the application.
- **Impact** - The security impact of the vulnerability if left unaddressed (e.g., data exposure, privilege escalation, account takeover).
- **Methodology** - The general approach and testing technique used to identify the issue, without exposing target-specific details.
- **Program Status** - Disclosure status where permitted (e.g., resolved, triaged, duplicate), noted only when consistent with program policy.

## Disclosure and Confidentiality Practices

All findings shared here comply with the responsible disclosure terms of the respective Bugcrowd programs. No proprietary source code, sensitive data, target URLs, or client-identifying information is included. Where a finding cannot be sanitized without losing its technical value, it is excluded from this repository entirely.

## Platform

Ongoing research and submissions are conducted through Bugcrowd, targeting programs within defined scope and adhering to each program's disclosure and safe harbor policies.
