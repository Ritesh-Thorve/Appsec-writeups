# TryHackMe - Practical Progress

## Overview

This repository documents hands-on learning and practice on TryHackMe (THM), covering guided rooms, capture-the-flag exercises, and skill-focused learning paths in offensive security. It reflects consistent, structured practice used to build and reinforce practical security fundamentals and applied exploitation skills.

Notes here focus on the reasoning and methodology behind each solve, rather than just final answers, to demonstrate genuine understanding of the underlying concepts.

## Purpose

The goal of this repository is to demonstrate:

- Consistent, hands-on practice across a range of security topics and difficulty levels.
- A working understanding of core concepts, from networking and Linux fundamentals to advanced exploitation techniques.
- The ability to apply theoretical knowledge to practical, scenario-based environments.
- Steady progression through structured learning paths relevant to offensive security and penetration testing.

## Areas Covered

- **Web Application Security** - Common vulnerability classes such as injection flaws, access control issues, and authentication bypasses, practiced in guided and CTF-style rooms.
- **Network and Infrastructure Security** - Service enumeration, exploitation of network-facing vulnerabilities, and lateral movement concepts.
- **Privilege Escalation** - Linux and Windows privilege escalation techniques across various room scenarios.
- **Fundamentals** - Core skills including networking, Linux/Windows administration basics, and scripting relevant to security work.
- **CTF and Challenge Rooms** - Standalone puzzles and capture-the-flag style exercises across multiple categories.

## Notes Structure

Each room write-up generally includes:

- **Room Name and Category** - The type of room and skill area it targets.
- **Objective** - What the room is designed to teach or test.
- **Approach** - The steps and reasoning used to work through the room.
- **Key Concepts** - Underlying security concepts reinforced by the exercise.

## Platform

Ongoing practice is conducted on TryHackMe, used as a structured supplement to broader, self-directed security research and bug bounty work.
